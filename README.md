# Business Cost Calculator

A mobile-first, browser-based calculator for any small business or product. Add material, packaging, and other costs; calculate cost per unit; compare suggested selling prices; and see profit, margin, potential revenue, and potential profit instantly.

All calculations run locally in the browser. The application has no authentication, database, or external API.

## Install

Requires a current version of Node.js (20 or newer is recommended).

```bash
npm install
```

## Run locally

```bash
npm run dev
```

Open `http://localhost:5173` in a browser. The project uses a small dependency-free development server.

## Test

```bash
npm test
```

## Production build

```bash
npm run build
```

The optimized production files are written to `dist/`. To inspect that build locally, run:

```bash
npm run preview
```
